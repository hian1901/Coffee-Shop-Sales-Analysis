# ☕ Coffee Shop Sales Analysis (MySQL)
An end-to-end SQL project focused on data cleaning, feature engineering, and exploratory business analysis on a retail coffee shop dataset (~150,000 transactions).
---
## 📌 Project Overview
This project processes raw transactional data into actionable business insights using **MySQL**. It covers the full data analysis pipeline: from cleaning dirty data and fixing encoding issues to calculating key business KPIs such as Month-over-Month (MoM) growth, peak hours, and product performance.
---
## 🛠️ Tech Stack & SQL Skills
* **Database:** MySQL 8.0+
* **Data Cleaning:** Duplicate detection (`ROW_NUMBER()`), UTF-8 BOM handling, Date/Time formatting (`STR_TO_DATE`).
* **Advanced SQL:** Window Functions (`LAG()`, `OVER()`), Common Table Expressions (CTEs), Conditional logic (`CASE WHEN`), Date/Time manipulation.
* **Business Metrics:** MoM Growth %, Peak Hours, Weekday vs. Weekend trends.
---
## 📊 Key Questions Answered
* **Growth Metrics:** What are the Month-over-Month (MoM) growth rates for Revenue, Order Volume, and Quantity sold?
* **Operations:** What are the peak operating hours during the day to optimize store staffing?
* **Consumer Patterns:** How does revenue distribute across days of the week, and Weekdays vs. Weekends?
* **Store & Menu Performance:** Which store locations and product categories (Coffee, Tea, Bakery) drive the most revenue?
